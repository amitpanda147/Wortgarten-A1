WORTGARTEN A1 — iPHONE HOME SCREEN WEB APP

This is a web app / PWA, not an App Store .ipa. No Mac needed.

INSTALL ON IPHONE (requires one-time web hosting)
1. In Safari, create a GitHub account if needed at https://github.com.
2. Create a NEW public repository, for example wortgarten-a1.
3. In the repository tap Add file > Upload files (Safari Request Desktop Website if necessary). Upload the contents of this folder, keeping icons/ as a folder. Or upload individual files and icons using GitHub web interface. Do NOT upload the ZIP as the site content.
4. In the repo select Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. After GitHub Pages publishes, open https://YOUR-USERNAME.github.io/wortgarten-a1/ in Safari.
6. Tap Share > Add to Home Screen > Open as Web App > Add.
7. Open Wortgarten from the Home Screen and load it once online. Offline access should then work.

IMPORTANT
- A downloaded HTML file alone cannot be installed with full PWA functionality. It must be served over HTTPS.
- GitHub Pages publishes the app code publicly, but your personal word lists/notes are stored in this device browser, not uploaded to GitHub. Avoid writing private details in repository files.
- Your old file:// browser data won't transfer automatically. Use Wortgarten's backup export/import to migrate when possible.
- Backup learning data regularly: device removal, storage cleanup, or changed app URL can lose local progress.
- Opening the site in Safari rather than via its Home Screen icon may use a different storage context on iOS.
